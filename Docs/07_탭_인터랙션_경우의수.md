## 한 장 표 (목표 스펙)

**읽는 법:** 행 = 상황, 열 = 플레이어 행동 → 결과.  
히트 우선순위: **자물쇠 > 요괴 몸 > 자원/공덕 더미(기물) > 맵**.  
말풍선·더미 숫자 그림은 탭 판정에 안 들어감 (몸/기물 bounds만).

**삭제:** 기물 요구 행·주저앉기 행.

### 주석

| | |
|---|---|
| ※1 | 기력0 놀기/쉬기 포함. **빈 기물에 드래그로 앉히면 재가동(무료)** |
| ※2 | 말풍선은 히트 대상 아님. 좌표가 기물 bounds면 수거 |
| ※3 | 윷놀이 복귀 후에도 자원/공덕은 **개별 수거** 유지. 일괄은 콜드스타트만 |
| ※4 | 기물 길게 누르기 → 개별 업그레이드 팝업 (우하단 “싼 것부터”와 병행) |

### 머리 위 우선순위

`공양 요구` > `혼잣말`  
(기물 요구 삭제. 요구가 뜨면 혼잣말 숨김.)

### 점유·생산

| 상태 | 자리 유지 | 생산 |
|------|-----------|------|
| 머물기 | ✅ | ✅ (resourceType별) |
| 기절 | ✅ | ❌ |
| 걷기 / 놀기·쉬기 | ❌ | ❌ |

요괴가 떠나도 **더미는 기물에 남음**.

### 복귀 환영 대사

놀고 있는 요괴의 「어서와」류.  
**새벽 4시(로컬) 기준 일일 첫 접속** — 출석 윷점 옥토끼 대사 끝나기 전 **환영 대사만** OFF.
