## 6-2. 행동 상태


| 상태       | enum          | 기획 요지 (3차)                                                | 구현                                 |
| -------- | ------------- | --------------------------------------------------------- | ---------------------------------- |
| 걷기       | `Walking`     | 빈 기물로 이동, 기력 소모 없음, 생산 0                                  | ✅                                  |
| 머물기      | `Staying`     | 기물에서 생산, **기력 10분당 1**                                    | ✅ (`1/600`)                        |
| ~~주저앉기~~ | ~~`Slumped`~~ | **삭제**                                                    | ✅ 런타임은 `Playing` (enum·세이브 호환만 잔존) |
| 놀기       | `Playing`     | 기력 0 또는 드롭·일할 기물 없음 → 맵 배회, 생산 0, **안 쓰러짐**. 드래그로 앉히면 재가동 | ✅                                  |
| 기절       | `Fainted`     | 기력0 놀기 **18시간** 후. **물**로 기력 0→1                          | ✅                                  |


기물당 1마리. **기절 중 점유 유지.** 놀기는 점유 해제.

### 기본 루프

`머물기` → (기력 남음·체류 종료) `놀기` → `걷기` → `머물기` …  
`머물기` → (기력 0) `**놀기`** → (18h) `**기절**` → 물 → 재가동

한 번 앉으면 **기력 고갈 또는 만창**까지 유지.  
만창이면 생산·기력 소모 **동시 정지**.

### 놀기 상세

- **진입:** ① 기력 0 ② 기물 밖 드롭 ③ 일할 수 있는 기물 없음
- **중:** 맵 랜덤 이동, 기력 소모·생산 없음. 혼잣말 유지. **음식 요구 가능**(기력0은 항상 ≤최대−25)
- **재가동:** 드래그로 빈 기물에 앉히면 `Staying`. 기력은 공양/물로만 회복
- **기절:** 기력0 놀기 타이머 18시간 → `Fainted`. 「깨우기」없음 — 상세에서 **물** 0→1. **요구 삭제·드래그 불가**

### 드래그

- 길게 누르기 → 들어올림. 가능 기물 = 금색 삼각형.
- 빈 기물 → 즉시 착석. 점유 중·조건 불일치(타 엔딩·떡절구 등) → **옆에 내려놓음**(착석 아님) → 2초 (x) → 놀기
- 바닥 → 2초 (?) → 놀기

### 복귀 환영 대사 및 출석 게이트

- 맵에 **놀고 있는** 요괴가 접속 시 「어서와」「기다렸어」류 대사 출력.
- **매일 새벽 4시(KST / UTC+9) 첫 접속**의 출석 윷점: 옥토끼 대사 종료 전까지 **모든 요괴 대사 억제**(혼잣말·인사).

### 윷놀이 귀환 상태 (보상 들고 있기)

- 윷놀이 종료 후 참가 요괴들이 자신이 획득한 아이템(부적, 특수칸 자원 등)을 **머리 위에 들고 있는 상태**로 맵에 복귀.
- 플레이어가 요괴(또는 아이콘)를 탭해 **개별 수거**하면 인벤토리로 지급되고 일반 상태(놀기/머물기)로 전환됨.

### 포인터 소유권

`MapPointerRouter` — UI 차단 → 캐릭터 드래그 / 맵 패닝 / 탭(혼잣말·획득품수거·자원수거·자물쇠).  
상세는 `[07](./07_탭_인터랙션_경우의수.md)`.

## 6-2. 걷기 목적지

### 기획

1. 빈 기물 중 랜덤 (직전·타 엔딩 기물 제외)
2. 선점되면 되돌지 않고 진행 방향 최근접 (구현은 단순화 가능)
3. 후보 없음·자리 없음 → **동일** 30초 방황 후 재추첨 (구분 없음)
4. 걷기 중 기력 소모 없음

### 현재 구현


| 항목                          | 상태                  |
| --------------------------- | ------------------- |
| 빈 기물 + 직전 제외 + 타 엔딩 제외 + 랜덤 | ✅                   |
| 예약 `TryReserve`             | ✅                   |
| 밀리면 즉시 재추첨                  | ⚠️ 기획의 “직진 최근접” 단순화 |
| 후보/자리 없음 → 30초 통합           | ✅                   |
| 걷기 중 기력 소모 없음               | ✅                   |
