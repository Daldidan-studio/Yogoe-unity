## 6-2. 걷기 목적지

### 기획 (원문 요약)

1. 목적지 = 지금 누군가 앉아 있는 기물을 뺀 나머지 중 **랜덤**
   - 직전 기물 제외
   - 다른 요괴의 엔딩 기물 제외
2. 가는 도중 그 기물에 다른 요괴가 먼저 앉으면 **되돌지 않고** 그대로 직진해  
   **진행 방향으로 가장 가까운** 기물로 간다.
3. 앞에 없으면 끝까지 갔다가 되돌아와 가장 가까운 기물로.
4. 후보가 없으면 **30초 걷고 재추첨**.
5. 자리가 없으면 걷거나 길바닥에 앉아 쉰다. **기력 소모 없음**.

### 현재 구현

| 항목 | 상태 | 비고 |
|------|------|------|
| 빈 기물 + 직전 제외 + 타 엔딩기물 제외 + 랜덤 | ✅ | `PropManager.GetRandomAvailableProp` |
| 예약(도착 전 선점)으로 동시 몰림 완화 | ✅ | `PropSlot.TryReserve` — 기획엔 없지만 실용상 추가 |
| 밀리면 되돌지 않음 | ⚠️ | 되돌아가진 않음. 대신 **즉시 랜덤 재추첨** |
| 진행 방향 최근접 기물 | ❌ | 경로 기하 없음 |
| 끝까지 갔다가 되돌아와 최근접 | ❌ | 미구현 |
| 후보 없음 → 30초 맵 방황 후 재추첨 | ✅ | `WanderRetrySeconds = 30` |
| 길바닥 앉기 연출 | ❌ | 방황 걷기와 동일 루프로 통합 |
| 걷기 중 기력 소모 없음 | ✅ | 소모는 머물기(`Staying`)만 |

`05` 10항: “후보없음” vs “자리없음” 구분이 기획에서 모호 → 현재 코드는 **한 방황 루프**로 통합.

## 6-2. 머물기 / 주저앉기 / 기절 / 놀기 (요약)

| 상태 | 기획 요지 | 구현 |
|------|-----------|------|
| 머물기 | 기물 5분, 기력 20초당 1, 생산 | ✅ (디버그 배속 `staminaDrainMultiplier` 주의) |
| 주저앉기 | 기력 0, 생산 0, 최대 12시간 | ✅ |
| 기절 | 12시간 방치, 상세 공양으로만 기상 | ✅ |
| 놀기 | 기물 아닌 곳에 드롭 시 5분 방황 | ❌ 드래그/놀기 미구현 |

기물당 1마리, 주저앉기·기절 중에도 점유 유지 — ✅ (`PropSlot`).
