## 6-2. 행동 상태

| 상태 | enum | 기획 요지 (최종 밸런스) | 구현(2026-09-16) |
|------|------|------------------------|-------------------|
| 걷기 | `Walking` | 빈 기물로 이동, 기력 소모 없음, 생산 0 | ✅ |
| 머물기 | `Staying` | 기물에서 생산, **기력 2분당 1** | ✅ |
| ~~주저앉기~~ | ~~`Slumped`~~ | **삭제** | ✅ 런타임은 `Playing`으로 이관 (enum·세이브 호환만 잔존) |
| 놀기/쉬기 | `Playing` | 기력 0 또는 드롭·체류종료 → 맵 배회, 생산 0, **안 쓰러짐**. 드래그로 앉히면 재가동(무료) | ✅ |
| 기절 | `Fainted` | 기력0 놀기/쉬기 **18시간** 후. 정화수로 기력 0→1 | ✅ |

기물당 1마리. **기절 중 점유 유지.** 놀기/쉬기(기력0 포함)는 점유 해제.

### 기본 루프

`머물기` → (기력 남음·체류 종료) `놀기` → `걷기` → `머물기` …  
`머물기` → (기력 0) **`놀기/쉬기`(기력0)** → (18h) **`기절`** → 정화수 → 재가동

### 놀기/쉬기 상세

- **진입:** ① 머물기 체류 종료 ② 기물 밖 드롭 ③ **기력 0** (주저앉기 대신)
- **중:** 맵 랜덤 이동, 기력 소모·생산 없음. 기력0이어도 쓰러지지 않음. **공양 요구 가능**
- **재가동:** 드래그로 빈 기물에 앉히면 `Staying` (무료). 기력은 별도 공양/정화수로만 회복
- **기절:** 기력0 놀기/쉬기 상태 타이머 18시간 → `Fainted`. 「깨우기」개념 없음 — 상세에서 정화수 1회당 기력 +1. **공양 요구 없음**
- **불가:** 넋·기절 중 앉히기 거부

### 복귀 환영 대사

- 맵에 **놀고 있는** 요괴가 접속 시 「어서와」「기다렸어」류
- **매일 새벽 4시(로컬) 첫 접속**의 출석 윷점 — 옥토끼 대사 종료 전까지 **이 환영 대사만** 억제

### 포인터 소유권

`MapPointerRouter` — UI 차단 → 캐릭터 드래그 / 맵 패닝 / 탭(혼잣말·더미수거·자물쇠).

## 6-2. 걷기 목적지

### 기획

1. 빈 기물 중 랜덤 (직전·타 엔딩 기물 제외)
2. 선점되면 되돌지 않고 진행 방향 최근접 (구현은 단순화 가능)
3. 후보 없음 → 30초 방황 후 재추첨
4. 걷기 중 기력 소모 없음

### 현재 구현

| 항목 | 상태 |
|------|------|
| 빈 기물 + 직전 제외 + 타 엔딩 제외 + 랜덤 | ✅ |
| 예약 `TryReserve` | ✅ |
| 밀리면 즉시 재추첨 | ⚠️ 기획의 “직진 최근접” 단순화 |
| 후보 없음 30초 | ✅ |
| 걷기 중 기력 소모 없음 | ✅ |
