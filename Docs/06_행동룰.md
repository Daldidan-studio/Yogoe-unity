## 6-2. 행동 상태 5종

| 상태 | enum | 기획 요지 | 구현 |
|------|------|-----------|------|
| 걷기 | `Walking` | 빈 기물로 이동, 기력 소모 없음, 생산 0 | ✅ (최근접 직진은 단순화) |
| 머물기 | `Staying` | 기물 5분, 기력 20초당 1, 생산 | ✅ |
| 주저앉기 | `Slumped` | 기력 0, 최대 12시간, 생산 0 | ✅ |
| 기절 | `Fainted` | 12시간 방치, 상세 공양으로만 기상 | ✅ |
| 놀기 | `Playing` | 기물 아닌 곳 드롭 → 5분 맵 방황, 기력·생산 없음 | ✅ 로직 / ⚠️ 드래그 UI는 미연결 |

기물당 1마리, 주저앉기·기절 중에도 점유 유지 — ✅ (`PropSlot`).

### 놀기 상세

- **진입:** `EnterPlaying()` — 머물기 중 기물이 아닌 곳에 내려놓았을 때 (드래그 UI가 호출).
- **중:** 5분간 맵 랜덤 이동, 기력 소모·생산 없음, 혼잣말 유지, 스프라이트는 `idle`.
- **종료:** 5분 후 → `Walking`. 기물에 올리면 `TrySitOnProp` → `Staying` 5분 새로 시작.
- **불가:** 넋·기절 중에는 진입/앉히기 거부.

## 6-2. 걷기 목적지

### 기획 (원문 요약)

1. 목적지 = 지금 누군가 앉아 있는 기물을 뺀 나머지 중 **랜덤**
   - 직전 기물 제외
   - 다른 요괴의 엔딩 기물 제외
2. 가는 도중 그 기물에 다른 요괴가 먼저 앉으면 **되돌지 않고** 그대로 직진해  
   **진행 방향으로 가장 가까운** 기물로 간다.
3. 앞에 없으면 끝까지 갔다가 되돌아와 가장 가까운 기물로.
4. 후보가 없으면 **30초 걷고 재추첨**.
5. 자리가 없으면 걷거나 길바닥에 앉아 쉰다. **기력 소모 없음**.

### 현재 구현

| 항목 | 상태 | 비고 |
|------|------|------|
| 빈 기물 + 직전 제외 + 타 엔딩기물 제외 + 랜덤 | ✅ | `PropManager.GetRandomAvailableProp` |
| 예약(도착 전 선점)으로 동시 몰림 완화 | ✅ | `PropSlot.TryReserve` |
| 밀리면 되돌지 않음 | ⚠️ | 즉시 랜덤 재추첨 |
| 진행 방향 최근접 / 끝까지 갔다가 복귀 | ❌ | 경로 기하 없음 |
| 후보 없음 → 30초 맵 방황 후 재추첨 | ✅ | `WanderRetrySeconds = 30` |
| 걷기 중 기력 소모 없음 | ✅ | |
