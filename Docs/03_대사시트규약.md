# 대사 시트 규약

Google Sheets로 대사를 관리하고, `npm run dialogue`로  
`Assets/Resources/Dialogue/{character}_tutorial.{locale}.json`에 반영한다.

시트: https://docs.google.com/spreadsheets/d/1Z3ZQquBl0XaYUz4Pxd1GXyn40p-83gUFyLNe5BZ4Uxc

---

## 1. 역할 분담

| 역할 | 하는 일 | 안 하는 일 |
|------|---------|------------|
| 기획 | `_index`에 있는 id의 **문구**·허용된 `layout`/`fx` 작성/수정 | 임의로 새 id·새 fx 클립 id 추가 |
| 개발 | id·연출 사전 확정, 코드 연결, export | 시트에 문구 하드코딩 |
| 공통 | 새 구간이 필요하면 **먼저 `_index`에 추가** | `_index` 없는 id로 시트 작성 |

`id`는 씬 이름이 아니라 **재생 타이밍 키**다. 코드가 이 키로 대사를 찾는다.

---

## 2. 스프레드시트 구조

### 탭

| 탭 | 용도 |
|----|------|
| `_index` | 허용 id 목록 + 한글 설명 (규약 원본) |
| `okto` | 옥토끼 (튜토리얼 예외 id 많음) |
| `{character}` | 본편 요괴 1마리 = 탭 1개 |

캐릭터 탭 이름 = 영문 소문자 코드 (`okto`, `doggabi` …).

### 캐릭터 탭 헤더

```
type | id | order | speaker | text_ko | text_en | narration | layout | fx | option_id | label_ko | label_en | note
```

지금은 한국어만 쓰면 `text_ko` / `label_ko`(또는 `label`)에 넣고, `text_en` / `text_zh`는 비워도 된다.
비어 있는 번역 칸은 export 시 `ko`로 폴백해 채운다.
`layout` / `fx`는 비워 두면 코드·카탈로그 기본값을 쓴다.

| type | 사용 컬럼 |
|------|-----------|
| `line` | `id`(section), `order`, `speaker`, `text_*`, `narration`, `layout`, `fx` |
| `choice` | `id`(choice set), `order`, `option_id`, `label_*` |

### 연출 컬럼 (`layout` / `fx`)

대사 한 줄에 붙는 **런타임 연출**이다. `note`는 사람용 메모(export 안 함), `layout`/`fx`는 JSON으로 나간다.

| 컬럼 | 용도 | 비우면 |
|------|------|--------|
| `layout` | 말풍선 위치 | `DialogueLayoutCatalog` 규칙(화자·나레이션·section) |
| `fx` | UI 연출 클립 id (`ui_anims.json`) | 재생 없음 |

**`layout` 허용값**

| 값 | 위치 |
|----|------|
| `bottom_wide` | 하단 와이드 |
| `near_yokai` | 요괴 근처 |
| `above_mortar` | 절구 위 |
| `top_narration` | 상단 나레이션 |

**`fx` 예** (클립 추가는 `Assets/Resources/Animation/ui_anims.json`)

`offer_react`, `evolve_flash`, `energy_warning_pulse`, `blacken`, `restore_white`, `glitch_on`, `glitch_off`

새 클립 id는 **먼저** `ui_anims.json`에 추가한 뒤 시트에 쓴다. 시트에만 있는 id는 런타임에서 무시(경고)된다.

## 3. id 규약

### 형식

- 영문 소문자 + 숫자 + `_` 만 (`snake_case`)
- 짧고 “언제”가 보이게: `evolve_manifest`, `story_1`
- 캐릭터 이름은 id에 넣지 않는다 → **탭이 캐릭터**

### 본편 요괴 공통 id (23마리 동일 키)

같은 육성 루프면 **탭만 다르고 id는 같게** 쓴다.  
코드는 `character + id`로 로드하고, 기획은 탭 복사 후 문구만 채운다.

| id | type | 언제 |
|----|------|------|
| `summon_intro` | line | 소환 직후 |
| `after_offer` | line | 공양 반응 (기본) |
| `pet` | line | 건드리기 |
| `need_energy` | line | 기력 부족 안내 |
| `energy_warning` | line | 기력 위험 경고 |
| `evolve_apparition` | line | 넋 → 괴 |
| `evolve_manifest` | line | 괴 → 혼 |
| `story_1` | line | 고유 스토리 1 |
| `story_2` | line | 고유 스토리 2 |
| `story_3` | line | 고유 스토리 3 (필요 시 확장) |
| `ending_prompt` | line | 엔딩 직전 안내 |
| `choice_ending` | choice | 승천 / 악귀화 선택 |
| `ending_ascend` | line | 승천 엔딩 |
| `ending_fall` | line | 악귀화 엔딩 |

고유 서사가 더 필요하면 `story_4`…를 `_index`에 추가한 뒤 사용한다.  
캐릭터 전용 특수 구간이 정말 필요하면 `special_{이름}` 형태로 `_index`에 등록한다.

### 선택지

| 필드 | 규칙 | 예 |
|------|------|----|
| `id` (choice set) | `choice_` 접두 | `choice_ending` |
| `option_id` | 코드 분기용 영문 | `ascend`, `fall` |
| `label_*` | 플레이어에게 보이는 문구 | 승천시켜 준다 |

`option_id`는 한번 정하면 바꾸지 않는다. 문구만 수정.

### 옥토끼 (예외)

튜토리얼 전용이라 공통 사전과 다른 id를 쓴다.  
예: `first_meeting`, `after_first_offering`, `training_intro`, `wish`, `blackening` …  
본편 23마리에 이 id를 복사하지 않는다.

## 4. `_index` 탭 컬럼

| id | kind | scope | description | when |
|----|------|-------|-------------|------|
| `pet` | line | main | 건드리기 반응 | 요괴 탭 |
| `choice_ending` | choice | main | 엔딩 선택지 | 친밀도 100 스토리 |
| `after_first_offering` | line | okto | 첫 공양 후 | 튜토리얼 STEP… |

- `kind`: `line` | `choice`
- `scope`: `main` (23마리 공통) | `okto` | 특정 캐릭터 코드

---

## 5. 작업 플로우

1. `_index`에서 쓸 id 확인 (없으면 추가 합의)
2. 캐릭터 탭 생성 (템플릿 탭 복제 권장)
3. 기획: `text_*` / `label_*` / `speaker` / `layout` / `fx` / `note`만 편집
4. 시트 공유: 링크 있는 사용자 · 뷰어
5. `npm run dialogue` → `Assets/Resources/Dialogue/{character}_tutorial.{locale}.json`
6. Unity Play로 확인

설정 파일: `Tools/dialogue_sheets.config.json`  
(`sheet_id`, `characters` 목록)

---

## 6. 금지 / 주의

- `_index`에 없는 id로 행 추가하지 않기
- 같은 탭에서 같은 `(type, id, order)` 중복하지 않기
- `option_id` 임의 변경 금지 (세이브·분기 깨짐)
- `layout` / `fx`에 허용 목록 밖 값 넣지 않기 (`ui_anims.json`·위 표 참고)
- 탭 이름에 한글·공백 쓰지 않기
- 본편 캐릭터에 옥토끼 튜토리얼 id 재사용하지 않기

---

## 7. 다국어

### 시트
- 캐릭터 탭 1개 유지
- 컬럼 추가: `text_ko`, `text_en`, `text_zh`, `label_ko`, `label_en`, `label_zh`
- 번역 없는 칸은 비워 둠 → export 시 `fallback_locale`(기본 `ko`) 문구로 채움

### export 결과
```
Assets/Resources/Dialogue/okto_tutorial.ko.json
Assets/Resources/Dialogue/okto_tutorial.en.json   # text_en/label_en 내용 있을 때만
Assets/Resources/Dialogue/okto_tutorial.zh.json   # text_zh/label_zh 내용 있을 때만
```

각 파일 내부는 기존과 동일하게 `text` / `label` 단일 필드 (+ `locale` 메타).

### 런타임
- `GameLocale.Current = "en"` 등으로 전환
- `OktoDialogue`가 `okto_tutorial.{locale}` 로드, 없으면 `ko` 폴백
- 설정: `Tools/dialogue_sheets.config.json`의 `locales`, `fallback_locale`
