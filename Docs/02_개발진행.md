# 개발 진행 — 옥토끼 튜토리얼 골격

## 실행 방법

1. Unity 6 (`6000.3.11f1`)로 프로젝트 연다.
2. `Assets/Scenes/SampleScene` 재생 (Play).
3. 별도 씬 배치 없이 `GameBootstrap`이 런타임에 족자 UI + 튜토리얼을 띄운다.

## 플레이 방식 (튜토리얼)

| 조작 | 용도 |
|------|------|
| 요괴(색 블록) 탭 | 건드리기 / 기력 부족 안내 |
| 대사 박스 탭 | 다음 대사 |
| 정화수 슬롯 드래그 → 요괴 위 드롭 | 공양 |
| 수련장 → 윷 던지기 | 강제 빽도 → 도 |
| 선택지 버튼 | 흑화 / 소원 분기 |

정식 루트: 소원에서 **옥토끼를 구해주세요** → 카드 → 향 3개 → 소환 플레이스홀더.

## 데이터 분리

| 종류 | 경로 |
|------|------|
| 대사·선택지 | `Assets/Resources/Dialogue/okto_tutorial.json` |
| UI 연출 클립 | `Assets/Resources/Animation/ui_anims.json` |

연출 재생: `UiAnimPlayer` (`Assets/Scripts/Animation/`). 클립 id 예: `offer_react`, `evolve_flash`, `energy_warning_pulse`, `blacken`, `dialogue_typewriter`.

대사 클릭: 타이핑 중 → 전체 표시 / 전체 표시 후 → 다음 대사.

## 코드 구조

```
Assets/Scripts/
  Bootstrap/GameBootstrap.cs   자동 기동
  Core/                        열거형·상수
  Data/OktoDialogue.cs         JSON 로더 (API 유지)
  Animation/                   연출 카탈로그 + 플레이어
  Model/GameState.cs           기력·친밀도·재화·카드
  Tutorial/TutorialController  STEP 1~14 스텝머신
  UI/ScrollScreenUI.cs         족자 셸 (런타임 UI)
Assets/Resources/Dialogue/
  okto_tutorial.json           옥토끼 튜토리얼 대사·선택지
Assets/Resources/Animation/
  ui_anims.json                shake / flash / pulse 등
```
