## 2. 이번에 맞춘 것 (최종 밸런스 2026-09-15 → 코드)

| 항목 | 상태 | 주요 위치 |
|------|------|-----------|
| 최대기력 `20 + 친밀도` (넋 상한 100) | ✅ | `CharacterAgent.MaxStamina` |
| 시작 기력 = 최대 (혼) / 넋 0 | ✅ | `StartingStateSettings` / `ApplyStartingState` |
| 머물기 기력 소모 **2분당 1** | ✅ | `CharacterAgent.Movement` (`1/120`) |
| 기력 0 → **놀기/쉬기** (주저앉기 진입 삭제) | ✅ | 런타임 `Slumped` → `Playing` 이관 (enum만 호환용 잔존) |
| 기력0 놀기 **18시간** → 기절 | ✅ | `Movement` / `OfflineSimulator` |
| 기물 요구 삭제 · **공양 요구만** | ✅ | `CharacterRequestState` |
| 공양 요구 상대경계(−5)·쿨 5분 · 기절 제외 | ✅ | `CharacterRequestState` |
| 일괄 수거 광고/보상권 **×2** | ✅ | `BatchCollectPopup` |
| 상점 **공덕 리셋 삭제** | ✅ | `ShopStock` / `ShopScreen` |
| 상점 UI **프리팹 전용** (런타임 Build 셸 제거) | ✅ | `ShopScreen.prefab` + `ShopScreenPrefabBaker` |
| 상세 하단바: 선호칩 3개여도 인벤 고정 | ✅ | `DetailScreen` Build + prefab (`PreferredHost` flex) |

## 3. 이미 돌아가던 코어 (유지)

- 맵·기물 슬롯·캐릭터 상태머신·생산/수거(공덕 중심)
- 상세(`DetailScreen`): 드래그 공양·정화수, 인벤 오버레이
- HUD·저장·오프라인 정산 골격
- 숫자 단위: `BigNumber`
- 윷: 보드/이동/UI·매치·보상 파이프라인 상당 부분 존재  
  (`YutMiniGame` / `YutMatch` / `YutRewards` 등 — K-SPIRITS 보드 계산 재사용)

## 4. 남은 작업

### 밸런스·루프 갭
- 기물 **타입별 개별 수거 더미** (지금은 공덕 `PendingMerit` 중심)
- 화덕/활터/약초밭 **산출 데이터 모델** ([`05` 1항](./05_기획_미확정사항.md))
- 기물 구매가 공식 확정 후 반영 ([`05` 2항](./05_기획_미확정사항.md))
- 출석(일일 윷점) UI → 콜드스타트 일괄과 순서 연동
- 업적 (기물 체계 안정 후)
- `Slumped` enum/세이브 필드 완전 제거(선택)

### 콘텐츠·시스템
- 소환/진화 UI 폴리시 (로직 골격은 있음)
- 선물꾸러미·요구 보상 연동 다듬기
- 사운드
- 도깨비불(패방) 등 11장 미정 항목

### 윷놀이 (부분 구현 · 기획 미확정 포함)
- [`05` 3~4항](./05_기획_미확정사항.md): 특수 칸 보상 구조, 말업기(스택) 규칙
- AI·캡처·승패/보상 폴리시 점검 (코드에 일부 있음 → 기획과 대조)

### 탭 UX ([`07`](./07_탭_인터랙션_경우의수.md))
- 말풍선/더미 hit 분리, 기절 단일탭 상세 여부 등 기획 확인 포인트
