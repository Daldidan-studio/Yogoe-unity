## 0. 한 줄 정의

아이들(idle) 육성 게임. 요괴를 족자(맵)에서 키우며 기물에 앉혀 **기물별 자원·공덕**을 생산하고,
공양·소환·진화·윷놀이·상점·업적·일일 윷점으로 루프를 돌린다.

**이번 델타 핵심:** 돌탑(돌사자)·우물·공덕 일괄 생산 체계를 폐기하고,
기물마다 다른 산출물(공덕 / 정화수 / 엽전 / 공양물)을 내는 6종 체계로 교체.
공덕은 떡절구만. 기물 요구 삭제. 친밀도는 최대기력. 기력 0은 놀기/쉬기 → 18시간 후 기절.

## 1. 캐릭터 (4종)

| 캐릭터 | 시작 단계 | 선호 공양물 |
|--------|-----------|-------------|
| 옥토끼 | 혼 | 꿀떡, 밥, 엿 |
| 삼족오 | 혼 | 복숭아, 신선로, 전통차 |
| 구미호 | 혼 | 생고기, 삼계탕, 밤, 대추 |
| 고라니 | 넋 (소환부터) | 사과, 수박, 인삼 |

**[결정] 성장 단계는 넋 → 혼 2단계.** (괴 단계 제거.)  
**넋:** 친밀도 **0 고정·상승 없음**. 기력은 **0에서 시작**, 정화수로만 충전 → **기력 100 도달 시 즉시 혼**. 자연 감소 없음. 행동 상태머신·혼용 최대기력 공식(`20+친`) 비적용.  
**혼 진입 후:** 친밀도 0부터, 최대기력 = `20 + 친밀도`.

옥토끼의 엔딩 기물은 떡절구 (전용 애니메이션). **앉으면 공덕 ×1** (MVP2차의 ×2 폐기).

## 2. 시작 상태

- 슬롯: 옥토끼(혼)/삼족오(혼)/구미호(혼)/4번째 빈칸(소환 입구)
- 초기 스탯: 시작 3인 친밀도 **50**, **최대·현재 기력 = 20 + 친밀도 → 70** (구 기력 100 폐기)
- 재화: 공덕 1,000 / 정화수 10 / 공양물 24종 각 1개 / 엽전 0 / 향 2
- 율(윷) 토큰: 시작 5개, 최대 5개, 30분마다 1개 충전
- **기물 6종 (교체):** 떡절구 · 옹달샘 · 갯바위 · 화덕 · 활터 · 약초밭  
  - **최종 밸런스:** 떡절구·옹달샘만 건립, 나머지 넷 자물쇠  
  - **테스트용(현재):** 여섯 전부 열어 둠

첫 소환(고라니)에는 향 3개 필요 — 3번째 향은 윷놀이 승리로 획득 (또는 상점에서 엽전으로 구매).

**구현:** `Assets/Resources/StartingStateSettings.asset` / `Main` → `GameEconomy.ApplyStartingState()`.  
화면 크기: `Assets/Resources/ArtScaleSettings.asset`.

## 4. 스탯: 친밀도 · 기력

| 항목 | 내용 |
|------|------|
| 친밀도 범위 | 혼 0~100. **넋은 0 고정·상승 없음** (혼 진입 시 0부터) |
| 친밀도 상승 | (혼만) 직접 선호 공양 +0.25 / 요구 들어주기(선호) +0.25 / 윷 말 이동 +0.25 |
| **최대 기력** | **혼:** `20 + 친밀도` (친50→70, 친100→120). **넋:** 혼용 공식 비적용, 진화용 기력 상한 **100** |
| 시작·회복 상한 | **혼:** 현재 기력은 최대기력으로 클램프, 시작 시 = 최대. **넋:** 기력 **0에서 시작**, 정화수로만 상승 |
| 기력 소모 | (혼·머물기) **2분당 1**. 걷기·놀기 중 소모 없음. 넋은 소모 없음 |
| 기력 0 | (혼) **놀기/쉬기** — 맵 배회, 안 쓰러짐. 드래그로 기물에 앉히면 재가동(무료) |
| 기절 | (혼) 기력 0 놀기/쉬기 **18시간** 후. 정화수로 기력 0→1 |
| 깨우기 | **개념 삭제**. 기절만 정화수로 살림 |
| 넋→혼 | 정화수로 기력 충전 → **100 도달 시 즉시 혼** |

친밀도는 **자원 기물 생산량에 보정하지 않음**(지구력=최대기력만).  
떡절구(공덕)만 기존처럼 친밀도 보정(`×(1+친/100)`) 유지.

시작 친밀도·기력 수치: `StartingStateSettings` (2장). 신규 소환 혼은 친밀도에 따라 최대기력 결정.

## 5. 맵과 행동 AI

행동 상태: 걷기 → 머물기(생산) → **[기력 0] 놀기/쉬기** → **[18시간] 기절** / 놀기(드롭·체류 종료).

**삭제:** 주저앉기(`Slumped`) 경로.  
룰 상세: [`06_행동룰.md`](./06_행동룰.md). 탭 경우의수: [`07_탭_인터랙션_경우의수.md`](./07_탭_인터랙션_경우의수.md).

- 걷기 목적지: 비어있고 직전 기물이 아니고 다른 요괴 엔딩기물이 아닌 곳 중 랜덤
- 기물당 1마리만 점유. **기절 중에도 점유 유지** (놀기/쉬기는 점유 해제·맵 배회)
- 넋 단계는 이 상태머신을 타지 않음 (고정 도깨비불, 정화수로만 진화)

**복귀 환영 대사:** 앱에 들어왔을 때 놀고 있는 요괴가 「어서와」「기다렸어」류 대사.  
**게이트:** 매일 **새벽 4시(로컬) 기준** 첫 접속의 **출석 윷점(14장)** — 옥토끼 대사가 끝나기 전에는 이 복귀 환영 대사만 막음 (일반 혼잣말·요구는 별도).

## 6. 생산·수거 (7장)

### 6-1. 산출물 타입 (`resourceType`)

기물 데이터에 `resourceType` 필드. 생산·수거·인벤·상점이 이 타입을 참조.

| resourceType | 의미 | 비고 |
|--------------|------|------|
| 공덕 | Merit | 떡절구만 |
| 정화수 | PurifiedWater | 옹달샘 |
| 엽전 | Yeopjeon | 갯바위 |
| 요리 / 사냥 / 채집 | 공양물 계열 | 화덕·활터·약초밭 — **인벤 적재 방식은 [`05`](./05_기획_미확정사항.md) 1항** |

### 6-2. 생산 공식

**떡절구(공덕) — 기존 체계 유지, 배율만 ×1**

- 분당 = `base(100) × 1.10^(L−1) × 친밀도보정 × 엔딩보정(×1)`  
- 보관 상한 ≈ 산출×30분치  
- 더미 단계 1~5 = 분당×1·3·10·20·30분 경계(「많이 쌓임」표시, 상한 아님)

**자원 기물 — 레벨만, 친밀도 무관**

| 기물 | 산출 | Lv1 산출시간 | 시작 보관 | 시간 감속 | 보관 |
|------|------|-------------|-----------|-----------|------|
| 옹달샘 | 정화수 | 15분/개 | 2 | −3%/Lv | +1 / 10Lv |
| 화덕 | 공양물·요리 | 30분/개 | 1 | −3%/Lv | +1 / 10Lv |
| 활터 | 공양물·사냥 | 30분/개 | 1 | −3%/Lv | +1 / 10Lv |
| 약초밭 | 공양물·채집 | 30분/개 | 1 | −3%/Lv | +1 / 10Lv |
| 갯바위 | 엽전 | 30분/개 | 1 | −3%/Lv | +1 / 10Lv |

- 보관량(개) = 시작보관 + `INT(레벨/10)` (상한 없음)  
- 방치 수익 = `min(보관량, 기력 다할 때까지 생산량)`  
- 가득 참: 맵에 작은 아이콘·은은한 빛

**옹달샘 진행 예시 (지시서 A-4-1)**

| Lv | 산출 시간 | 보관 | 방치 30분 | 꽉 차는 시간 |
|----|-----------|------|-----------|--------------|
| 1 | 15.0분/개 | 2 | 2개 | 30분 |
| 10 | 11.4분/개 | 3 | 2.6개 | 34분 |
| 20 | 8.4분/개 | 4 | 3.6개 | 34분 |
| 30 | 6.2분/개 | 5 | 4.8개 | 31분 |
| 50 | 3.4분/개 | 7 | 7개 | 24분 |

### 6-3. 수거

| 종류 | 방식 |
|------|------|
| 자원(정화수·엽전·공양물) | 기물 탭 **개별 수거** (기물별 더미). **윷놀이 복귀 후에도 개별** |
| 공덕 | 떡절구 더미 탭 수거 (본편 제단 합산은 MVP 제외) |
| 일괄 수거 | **앱 완전 종료 후 재실행(콜드스타트)만**. 옥토끼 슬롯 위 버튼. 오프라인분+미수거 더미. **받기(1배) / 광고·보상권 2배**. 백그라운드 복귀만으로는 비표시 |

## 8. 소환과 진화 (9장)

- 소환: 빈 슬롯 탭 → 향 3개 → 고라니(넋) (MVP 고정). 넋 시작: 친밀도 0, 기력 0

## 9. 요구(퀘스트)와 선물꾸러미 (10장)

### 9-1. 기물 요구 — **삭제**

발생 조건·생각말풍선·옮겨주기 판정·관련 선물꾸러미 트리거 전부 제거.  
요구는 **공양물 요구만**.

### 9-2. 공양물 요구

| 항목 | 내용 |
|------|------|
| 발생 | 현재 기력 ≤ `(최대기력 − 20)` 인 구간에서, **−5 절대경계**를 하향 통과할 때마다 (예: 최대 30이면 경계 10, 5…) |
| 노출 | 1분 후 소멸 |
| 쿨다운 | 완료 후 **5분** 뒤 다시 요구 가능 |
| 상한 | 요괴별 동시 1개 |
| 제외 | **넋·기절** 중 발생 안 함. **놀기/쉬기(기력0 포함)는 요구 가능**. 앱 종료 시 삭제 |
| 완료 | 기력+30·친밀도+0.25(+선물꾸러미 판정) |

### 9-3. 선물꾸러미 — 유지

확률 1/5, 4연속 빈손 후 5번째 보장, 유저 단위 카운터, 첫 요구 확정 지급.  
내용: 공양물 25% / 정화수 50% / 광고보상권 25%.  
개봉 후 광고 보고 하나 더(세션 1회). 광고보상권으로 동일. 광고 SDK 스텁.

## 14. 출석보상 윷점 (일일 첫 접속)

- 판: 일자 7칸 `ㅇ-ㅇ-ㅇ-ㅇ-ㅇ-ㅇ-ㅇ` (윷판 일자)
- 칸 엽전 표시: **5 · 5 · 5 · 7 · 9 · 10 · 20**
- 클릭 → 해당 엽전 지급 + 윷 3개 빠른 연출(윷놀이 이무기 던지기와 유사)
- 결과에 따라 **옥토끼 대화창**(스토리 대화창 형식, 슬롯을 가림)
- **게이트:** 옥토끼 대사 종료 전 → 요괴 **복귀 환영 대사만** 억제. 일반 혼잣말·공양 요구는 그대로.

일괄 수거(콜드스타트)와 겹치면: **출석 윷점 → (옥토끼 대사) → 일괄 수거 팝업**.
