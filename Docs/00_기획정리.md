## 0. 한 줄 정의

아이들(idle) 육성. 요괴를 족자(맵)에서 기물에 앉혀 **기물별 자원·공덕**을 생산하고,
**화덕→공양간(요리)** · 공양 · 소환 · 윷놀이 · 상점 · 출석 윷점으로 루프를 돌린다.

| 포함 | MVP 제외 |
|------|----------|
| 기물 6종 · 음식 요구 · 공양간 · 윷 · 상점 · 출석 윷점 | **넋** 단계 · 기물 요구 · 특별 공양 퀘스트 · 제단 · 채색 · 패방 · 업적 |

소환 즉시 **혼**. 공덕은 떡절구만. 화덕은 생산 없음(요리 입구).

## 1. 캐릭터 (4종)

| 캐릭터 | 합류 | 선호 공양물 |
|--------|------|-------------|
| 옥토끼 | 시작(혼) | **없음** |
| 삼족오 | 시작(혼) | 신선로 · 화채 · 약주 |
| 고라니 | 첫 소환(혼) | 백설기 · 한약 · 비빔밥 |
| 구미호 | 4슬롯 해금(엽전 99) 후 소환(혼) | 생고기 · 꽃막걸리 · 약주 |

- 선호는 **최초 비공개**. 해당 공양물을 한 번 성공 지급하면 영구 공개(상세·금테).
- 옥토끼 엔딩기물 = 떡절구(전용 애니). 앉으면 공덕 ×1.  
  엔딩기물 2개 ↔ 떡절구 레벨 연동 → 미확정 [`05`](./05_기획_미확정사항.md) 4항.

## 4. 스탯: 친밀도 · 기력 · 공양

### 용어

| 구분 | 수급 | 기력 | 친밀도 |
|------|------|------|--------|
| 음식 | 공양간(재료 2) · 36종 | **+8** | 0 |
| 공양물 | 공양간(재료 3) · 24종 | **+3** | **+2** |
| 선호 공양물 | 요괴별 최대 3종 | **+3** | **+5** |
| 물(정화수) | 옹달샘 · 요리 재료 | **+3** | 0 |
| 음식 요구 완료 | — | **+12** | 0 |

부록 A 헤더(+25 등)는 무시. **본문 §5 수치만** 적용(위 표).

### 친밀도

| 항목 | 내용 |
|------|------|
| 범위 | 0~100 (소수 화면 비표시) |
| 상승 | 일반 공양 **+2** · 선호 **+5** · 해당 요괴 윷 말 이동마다 **+0.25** |
| 미변동 | 음식 · 물 · 음식 요구 · 부적 |
| 역할 | **최대 기력만** (= `25 + 친밀도`). 자원 기물 생산량 보정 없음 |

윷 **말업기** 시 +0.25 횟수 → 미확정 [`05`](./05_기획_미확정사항.md) 7항.

### 기력

| 항목 | 내용 |
|------|------|
| 최대 | `25 + 친밀도` (친50→75, 친100→125) |
| 소모 | 머물기(작업) 중 **10분당 1**. 걷기·놀기 **0**. 오프라인 동일 |
| 만창 | 보관 가득 → **생산·기력소모 동시 정지** |
| 기력 0 | **놀기/쉬기**(배회, 안 쓰러짐). 드래그로 기물 앉히면 재가동 |
| 기절 | 기력 0 유지 **18시간** 후. **물만**으로 0→1 |
| 삭제 | 주저앉기 · 깨우기 |

## 6. 생산·수거 (7장)

### 6-1. `resourceType`

| type | 의미 | 기물 |
|------|------|------|
| 공덕 | Merit | 떡절구 |
| 물 | PurifiedWater | 옹달샘 |
| 엽전 | Yeopjeon | 갯바위 |
| 요리(cook) | **재료 아님** — 생산 없음 | 화덕 → 공양간 |
| 사냥 | hunt 재료 | 활터 |
| 채집 | gather 재료 | 약초밭 |

### 6-2. 기물별 산출

| 기물 | 산출 | Lv1 | Lv1 보관 | 레벨업 | 사용 |
|------|------|-----|----------|--------|------|
| 떡절구 | 공덕 | 분당 `100×1.10^(L−1)` | ≈30분치 | 산출×1.10/Lv | 옥토끼만 |
| 옹달샘 | 물 | 30분/개 | **6** | 시간×0.97^(L−1), 보관+INT(L/10) | 전원 |
| 갯바위 | 엽전 | 1시간/개 | **1** | 동일 | 전원 |
| 활터 | 사냥 재료(§7-3) | 20분/개 | **9** | 동일 | 전원 |
| 약초밭 | 채집 재료(§7-3) | 20분/개 | **9** | 동일 | 전원 |
| 화덕 | **없음** | — | — | **레벨업 없음** | 탭→공양간 |

- 자원 산출시간: `T₁ × 0.97^(L−1)` (−3%/Lv 복리). 고레벨 하한 캡 → 미확정 [`05`](./05_기획_미확정사항.md) 2항.
- 보관 = 시작개수 + `INT(Lv/10)` (상한 없음).
- 방치: `min(보관, 기력 다할 때까지 생산량)`. 만창 시 생산·소모 정지.

## 10. 윷놀이 (11장)

- 상대: 이무기(승패). 토큰 1 소모(시작5/최대5/30분+1).
- 팀: 옥토끼 + 슬롯 전원(소환 직후 포함). 29칸 · 지름길 · 말업기.
- 이무기 AI: 말 **1개**. **잡기 우선**, 없으면 전진.
- 특수칸 5:
  - 재료보따리 1 → 재료 3(선물과 동일 추첨)
  - 물 1 → 물 1
  - 엽전 2칸 → 각 엽전 1
  - 보물상자 1 → 공양물 **50%** / 광고보상권 **30%** / 향 **5%** / 엽전×3 **15%**
- 말 **완주** → 부적 **1**(6종 **균등**, 임시 확정).
- 해당 요괴 말 이동마다 친밀도 **+0.25**.
- 복귀 후 기물 **자동 수거 없음**.
