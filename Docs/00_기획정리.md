## 0. 한 줄 정의

아이들(idle) 육성 게임. 요괴를 족자(맵)에서 키우며 기물에 앉혀 공덕을 생산하고,
공양·소환·진화·윷놀이·상점·업적으로 루프를 돌린다.

---

## 1. 캐릭터 (4종)

| 캐릭터 | 시작 단계 | 선호 공양물 |
|--------|-----------|-------------|
| 옥토끼 | 혼 | 꿀떡, 밥, 엿 |
| 삼족오 | 혼 | 복숭아, 신선로, 전통차 |
| 구미호 | 혼 | 생고기, 삼계탕, 밤, 대추 |
| 고라니 | 넋 (소환부터) | 사과, 수박, 인삼 |

**[결정] 성장 단계는 넋 → 혼 2단계.** (괴 단계 제거.)
진화: 정화수로만 기력 충전 → **기력 100 도달 시 즉시 혼**, 친밀도 0부터. 넋 기력은 자연 감소 없음.

옥토끼의 엔딩 기물은 떡절구 (전용 애니메이션, 생산 x2).

---

## 2. 시작 상태

- 슬롯: 옥토끼(혼)/삼족오(혼)/구미호(혼)/4번째 빈칸(소환 입구)
- 초기 스탯: 3인 친밀도 50, 기력 100
- 재화: 공덕 1,000 / 정화수 10 / 공양물 24종 각 1개 / 엽전 0 / 향 2
- 율(윷) 토큰: 시작 5개, 최대 5개, 30분마다 1개 충전
- 기물: 돌사자·우물·떡절구 건립 완료, 초가집·그네·솟대문 자물쇠 (기획 원문 “돌탑” → 현재 아트 돌사자)

첫 소환(고라니)에는 향 3개 필요 — 3번째 향은 윷놀이 승리로 획득 (또는 상점에서 엽전으로 구매).

**구현:** 위 숫자는 코드에 박지 않고  
`Assets/Resources/StartingStateSettings.asset` 에서 관리한다.  
`Main` 부팅 시 `GameEconomy.ApplyStartingState()`로 적용.  
(공양물은 현재 에셋 5종만 연결되어 있음 — 24종 추가 시 이 에셋 목록에만 넣으면 됨.)

화면 크기(카메라·캐릭터·기물·맵 overscan)는  
`Assets/Resources/ArtScaleSettings.asset` 에서 관리.

## 3. 숫자 단위계 (무한 확장)

1,000 미만은 그대로, 이후 ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅊㅋㅌㅍㅎ(14자) 순서로 3자리씩 확장,
ㅎ을 넘어가면 ㄱㄱ→ㄴㄴ→... 식으로 같은 순서를 겹쳐서 무한 확장.
구현: `Assets/Scripts/Core/BigNumber.cs`.

## 4. 스탯: 친밀도 · 기력

| 항목 | 내용 |
|------|------|
| 친밀도 범위 | 0~100, 넋 단계는 없음 (혼 진입 시 0부터) |
| 친밀도 상승 | 직접 선호 공양 +0.25 / 요구 들어주기(선호) +0.25 / 윷 말 이동 +0.25 (`05` 1항 확정) |
| 기력 범위 | 0~100, 상한 100 |
| 기력 소모 | 머물기 중 1분당 3 (오프라인 동일 속도), 걷기 중 소모 없음 |
| 기력 0 | 주저앉기 → 12시간 공양 없으면 기절 |

시작 친밀도·기력 수치는 `StartingStateSettings` (위 2장).

## 5. 맵과 행동 AI

행동 상태 5종: 걷기 → 머물기(생산) → 주저앉기(기력 0) → 기절(12시간 방치) / 놀기(드롭).
구현: `Assets/Scripts/Characters/CharacterAgent.cs`, `PropSlot.cs`, `PropManager.cs`.
**룰 기준 문서:** [`06_행동룰.md`](./06_행동룰.md) (기획 vs 구현 표).

- 걷기 목적지: 비어있고 직전 기물이 아니고 다른 요괴 엔딩기물이 아닌 곳 중 랜덤
- 기물당 1마리만 점유, 주저앉기·기절 중에도 점유 유지
- 놀기: `EnterPlaying()` / 기물 앉히기 `TrySitOnProp` (드래그 UI는 추후 연결)
- 넋 단계는 이 상태머신을 타지 않음 (고정 도깨비불로 취급, 정화수로만 진화)

## 6. 공덕 생산·수거 (7장)

**생산 (7-1):** 머물기(`Staying`) 중인 요괴만. 분당 = 기물기본×1.1^(L-1)×친밀도보정×엔딩보정.  
주저앉기·기절·걷기·빈 기물 = 0. 생산분은 **기물 더미**에만 쌓임 (`PropSlot.PendingMerit`).

**수거 (7-2):** 기물 탭 → 더미를 `GameEconomy` 공덕(HUD)으로 이동. 요괴가 떠나도 더미는 기물에 남음.  
더미 단계 1~5 = 분당기본×1·3·10·20·30분 경계.  
연출: `MeritCollectFx` 꽃잎 흩뿌림 → HUD 공덕으로 비행.  
**일괄 수거:** 앱 콜드스타트 시 기물 더미 → `PendingBatchMerit`, 옥토끼 슬롯 위 버튼.  
팝업에서 **받기(1배)** / **광고·보상권 ×3** (`BatchCollectPopup`, 광고 SDK는 스텁). 백그라운드 복귀만으로는 안 뜸.

---

## 7. 기물 (8장)

- 최초 구매: 800 × 1.4^(n-1) (n=구매 순서) — 자물쇠 탭 → 팝업 `[건설]`/`[닫기]`
- 업그레이드: 500 × 1.15^(L-1), 우하단 최저가 버튼(탭 1회 / 꾹=연속), `+1 급` 이펙트
- 시작: 우물·돌사자·떡절구 건립, 초가집·그네·솟대문 자물쇠
- 떡절구: 옥토끼 전용·앉으면 공덕 ×2. **미구현:** 찧기/기도 전용 애니메이션
- 세이브: `isBuilt`, `propsPurchasedCount`

---

## 8. 소환과 진화 (9장)

- 소환: 빈 슬롯 탭 → 향 3개 소모 → 고라니(넋) 등장 (MVP 소환 대상 고정)
- 진화: 정화수로만 기력 충전 → 기력 100이면 즉시 혼 (친밀도 0부터). 넋은 자연 기력 감소 없음.

---

## 9. 요구(퀘스트)와 보상상자 (10장)

기력이 10단위 경계를 하향 돌파할 때마다 선호 공양물 요구 발생. 완료 시 기력+30·친밀도+0.25(+선물꾸러미 판정).
요괴별 5분 쿨다운. 넋·주저앉기·기절 중엔 발생 안 함. 기절/앱종료 시 삭제(세션 간 유지 안 됨).
선물꾸러미 개봉 후 **광고 보고 하나 더**(세션 1회). 광고보상권 보유 시 권 소모로 동일. 광고 SDK는 스텁.

---

## 10. 윷놀이 (11장)

상대: 이무기, 승패 있음. 진입 재화: 윷 토큰(시작5/최대5/30분당1충전).
팀: 옥토끼 + 현재 슬롯의 혼 전원(넋 불참). 29칸 판, 지름길, 특수칸, 말 업기.
승리: 내 말 아무거나 하나 골인 시 즉시 승리(05번 3항 확정).

**재사용:** 이전 KSpirits 프로젝트에 이미 만들어져 있던 순수 로직·UI를 그대로 가져다 씀
(`Assets/Scripts/Minigames/Yut/` — 보드 좌표, 이동 경로 계산, 던지기 확률표, 절차적 UI).
**아직 없음:** 승패 판정, 이무기 AI(잡기 우선순위), 말 업기 시 보상 분배, 향/엽전 보상 지급 로직.

---

## 11. 상점 (12장 고가구점)

- HUD 우상단 **상점** / 소환 향 부족 시 동일 화면
- 배경 고가구점 내부, 중앙 이무기 탭 → 대사 순환 (`어서 오거라.` / `뭐가 더 필요하냐.` / `천천히 둘러보아라.`)
- 책상 위: 음식 / 향 / 음식 — 좌·우 공양 2시간마다 랜덤, 각 **10 엽전**; 향 **20 엽전**
- 엽전 부족: `"돈을 더 모아와라."`
- **5분치 공덕**으로 슬롯 리셋 (`ShopStock.GetCurrentProductionPerMinute()×5`, 생산 0이면 건립 기물 기본합×5)
- 책상 아래 패키지 3종 스크롤 — 상세 팝업만, **결제 연동 없음**

업적 (13장) / 저장·오프라인 정산 (15장) / 메인맵 도깨비불 (16장): PDF 원문 — 상점 외 아직 미구현.
