# CI 배포 (WebGL → GitHub Pages)

`main` 브랜치에 push하면 GitHub Actions가 WebGL을 빌드하고 Pages에 배포한다.

**플레이 URL (배포 후):**  
https://daldidan-studio.github.io/Yogoe-unity/

---

## 1. GitHub Pages 활성화 (1회)

1. GitHub repo → **Settings → Pages**
2. **Build and deployment → Source:** `GitHub Actions`

---

## 2. Unity Secrets 등록 (1회)

[GameCI Activation](https://game.ci/docs/github/activation) 참고.

1. Unity Hub → Preferences → Licenses → **Personal License** 활성화
2. `.ulf` 파일 내용 복사  
   - Mac: `/Library/Application Support/Unity/Unity_lic.ulf`
3. Repo → **Settings → Secrets and variables → Actions** → New repository secret

| Secret | 값 |
|--------|-----|
| `UNITY_LICENSE` | `.ulf` 파일 전체 내용 |
| `UNITY_EMAIL` | Unity 계정 이메일 |
| `UNITY_PASSWORD` | Unity 비밀번호 (특수문자 없을수록 안전) |

---

## 3. Unity Hub 모듈

로컬·CI 공통으로 **WebGL Build Support** 모듈이 필요하다.  
(Unity 6 `6000.3.11f1` 설치 시 모듈 추가)

---

## 4. 배포 확인

1. `main`에 push
2. **Actions** 탭 → `Build & Deploy WebGL` 워크플로 성공 확인
3. Settings → Pages 또는 Actions run summary에서 URL 확인

첫 빌드는 20~30분, `Library` 캐시 후 10~15분 정도.

---

## 5. 수동 실행

Actions → **Build & Deploy WebGL** → **Run workflow**

---

## 6. 트러블슈팅

| 증상 | 확인 |
|------|------|
| License activation failed | Secrets 3개 재등록, 비밀번호 특수문자 제거 |
| No space left on device | `free-disk-space` step 포함됨 — 재실행 |
| 빈 화면 / 404 | Pages Source가 GitHub Actions인지 확인 |
| 에셋 로드 실패 | `index.html`에 `<base href="/Yogoe-unity/">` 주입됨 — 레포 이름 변경 시 workflow `BASE_PATH` 수정 |
| `SyntaxError: Invalid or unexpected token` | WebGL 압축을 Gzip + Decompression Fallback으로 설정 (GitHub Pages는 Brotli `Content-Encoding` 미지원) |

워크플로: `.github/workflows/build-and-deploy.yml`
