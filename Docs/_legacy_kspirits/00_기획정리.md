## 0. 한 줄 정의

한국 설화 기반 **육성 시뮬레이션 + 카드 수집**.  
나전칠기 선반장에서 탈출한 요괴 23마리를 족자에서 키우고, 선택에 따라 승천/악귀화시키며 양면 요괴패를 모은다.

**MVP 목표:** 옥토끼 튜토리얼 완전 구현 → 첫 소환 요괴 1마리 완전 육성 및 엔딩.

## 1. 세계관 (확정)

| 항목 | 내용 |
|------|------|
| 봉인구 | 나전칠기 선반장 (검은 옻칠 + 오색 자개). 칸마다 봉인 족자 |
| 결계 | 선반장에 붙은 부적 |
| 봉인 대상 | 요괴 23마리 (옥토끼 제외) |
| 가시성 | 요괴를 볼 자질이 있는 사람에게만 선반장이 보임 |
| 시작 사건 | 손님(플레이어)이 "예쁘다" → 옥토끼가 발을 걸어 선반 전복 → 부적 찢김 → 23마리 탈출 |
| 이무기 | 상점 주인. 999년 묵은 이무기. 옥토끼의 주인. 잘생긴 남성, 백발보석안. 요괴를 잡아 봉인해 온 존재 |
| 플레이어 계약 | 이무기의 요구로 요괴를 전부 잡아와 족자에서 돌보고 기록 |

## 2. 핵심 플레이 루프 (확정)

1. 향 3개로 요괴 소환  
2. 족자에서 육성 (공양 · 수련 · 건드리기)  
3. 기력 · 친밀도 관리 → 진화 (넋→괴→혼) → 스토리 4편  
4. 스토리 선택지로 엔딩 (승천/악귀화) → 요괴패 등록  
5. 윷놀이로 엽전 수급 → 향 구매 → 다음 소환  

도망: 기력 0 또는 친밀도 0 후 **6시간** 유예 → 기록 미달.

## 4. 육성 파라미터 (확정)

파라미터는 **기력 + 친밀도** 2개. 엔딩은 스토리 선택지로만 결정.

### 4-1. 기력
| 항목 | 수치 |
|------|------|
| 최대 | 100 |
| 감소 | 20분당 -1 (100→0 ≈ 33시간) |
| 0 후 유예 | 6시간 → 도망 (마지막 공양~도망 ≈ 39시간) |
| 공양 1회 | +20 (정화수 포함) |
| 윷 말 이동 | +5 (이동한 요괴만) |
| 하트 충전(기력 소모) | -20 (하트 0일 때만) |

### 4-2. 친밀도
| 항목 | 수치 |
|------|------|
| 최대 | 100 |
| 시간 감소 | 없음 |
| 0 후 유예 | 6시간 → 도망 |
| 윷 말 이동 | +2 |
| 선호 공양 | +3 |
| 비선호 공양 | -3 |
| 48시간 수련 미실시 | -10 |

### 4-3. 하트 (수련 자원)
| 항목 | 수치 |
|------|------|
| 최대 | 5 |
| 자연 충전 | 30분마다 1개 |
| 리워드 광고 | 하트 1 / 하루 5회 |
| 윷 1회 | 하트 -1 (윷·모 보너스는 무료) |

### 4-4. 정화수
- 기력 +20, 친밀도 변동 없음
- 선호/비선호 없음 (옥토끼만 선호로 지정)
- 넋 단계: 정화수만 공양 가능

### 4-5. 건드리기
1. 1% 아이템 드롭 (6시간 쿨, 괴·혼만)  
2. 30% 대사 (괴·혼만)  
3. 나머지 비언어 리액션 (전 단계)

## 5. 진화 · 스토리 · 엔딩 (본편 확정)

| 단계 | 최소 시간 | 기력 | 친밀도 | 스토리 |
|------|-----------|------|--------|--------|
| 넋 | 12시간 | 진화 시 100 | 10+ | 없음 |
| 괴 | 2일 | 진화 시 100 | 20+ | 소개편 (친밀도 25) |
| 혼 | 4일 | — | — | 1·2·3차 (50 / 75 / 100) |
| 합계 | ≈7일 | | | 총 4편 |

진화 연출: 조건 미충족 시 넋/괴·괴/혼 지직거림. 탭 시 "기력이 모자라요". 기력 100이면 마법소녀식 진화 연출.

| 엔딩 | 조건 | 결과 |
|------|------|------|
| 승천 | 친밀도 100 + 선한 선택 | 카드 앞면 |
| 악귀화 | 친밀도 100 + 악한 선택 | 카드 뒷면. 이무기가 탁기 흡수 |
| 도망 | 기력/친밀도 0 후 6시간 | 카드 미해금. 회수권으로 복귀 |

양면(승천+악귀화) 완성 요괴만 재육성 풀 대상 (MVP 이후).

## 6. 소환 · 슬롯 · 재화 (확정 방향 / 숫자 충돌 있음 → §12)

- 소환: 향 3개. 완전 랜덤. 희귀도·지명 없음. 향 1개 = 엽전 12개.
- 순서: ① 옥토끼(튜토리얼) → ②~④ 보장 3인방 순차 → ⑤~ 나머지 랜덤
- 슬롯: 기본 1 / 최대 3. 옥토끼는 슬롯 미차지.
- 재화: 엽전(단일) / 향(소환) / 하트(수련)
- 광고: 상시 광고 + 하트 리워드만. 광고 제거 구매 시 상시만 제거.

## 8. 옥토끼 튜토리얼 (명세서 v1.0 — 개발 확정)

> 본편 규칙과 **예외**. 대사는 명세서 그대로 사용.

### 8-1. 캐릭터
- 말투: 유쾌·수다·존댓말. 헤헤/히히/뿅/짜잔
- 선호: 꿀떡 · 팥떡 · 정화수 (금색 테두리)
- 역할: 튜토리얼 안내 → 종료 후 윷놀이/파밍 상주
- 예외: 진화 시간 무시(즉시) / 개별 승천·악귀·도망 없음 / 업보 예외(기억이 온전한 자 → 선택지는 현재 감정만)

### 8-2. 14스텝 진행표

| # | 스텝 | 트리거 | 학습 |
|---|------|--------|------|
| 1 | 첫 대면 (넋 도깨비불) | 자동 | 건드리기 |
| 2 | 첫 공양 | 정화수 드래그 | 공양 = 기력 |
| 3 | 괴 진화 | 자동(즉시) | 진화 |
| 4 | 쓰다듬기 | 탭 | 건드리기 보상 |
| 5 | 수련 (윷) | 수련 버튼 | 수련 = 기력+친밀도 |
| 6 | 아이템 회수 | 자동 | 아이템 획득 |
| 7 | 기력 경고 | 자동 | 방치 = 도망 |
| 8 | 재공양 → 혼 진화 | 정화수 → 기력100 | 최종 진화 |
| 9 | 기억 관람 1·2·3차 | 친밀도 80/90/100 | 스토리 UI |
| 10 | 흑화 선택지 | 선택지 3종 | 예외의 법칙 |
| 11 | 흑토끼 도망 | 자동 | 선택의 무게 |
| 12 | 이무기 복원 | 자동 | 탁기 흡수 복선 |
| 13 | 사죄와 소원 | 선택지 2종 | 도플갱어 / 히든0 |
| 14 | 카드 완성 + 향3 | 자동 | 종료 → 소환 |

### 8-3. 스텝별 핵심 연출 (확정 대사 요약)

**STEP 1–2**  
빈 족자 + 도깨비불. 탭 → "……". 나레이션: 공양이 필요.  
기력바·정화수 펄스 → 정화수 드래그 → 기력 +20, 부르르.  
이후 옥토끼가 넋인데도 말함(예외 설명) → "자, 지금은 제가 알아서 클게요. 뿅!"

**STEP 3–5 (수련 강제 시퀀스)**  
즉시 괴 진화. (대사: "이 상태는 **귀**라고 해요" — 표기 확인 필요, §12)  
수련장 강조 → 하트 소모 설명 → 강제 **빽도** → 시작점에서 뒤로 → 엽전칸 → 엽전 +1  
→ 강제 **도** → 완주 → 정화수 획득 → 수련장 퇴장

**STEP 8**  
기력 80, 괴/혼 지직거림. 탭 시 "기력이 모자라요".  
정화수로 100 → 혼 진화(인간형).  
※ 명세서에 "튜토리얼 종료" 나레이션이 여기에도 있음 → 실제 종료는 STEP 14. **문구 위치 수정 필요 (§12)**

**STEP 9 기억 (친밀도 70 시작)**  
| 친밀도 | 편 | 내용 |
|--------|----|------|
| 80 | 달 | 절구·떡 찧기·별똥별·지구로 |
| 90 | 지구 | 화려함·굶주림·쓰러짐·이무기 구출 |
| 100 | 고가구점 | 일·은혜·선반장·손님·발을 건 날·"자유롭게 해주실 거라 믿어요" |

**STEP 10 흑화 (전부 동일 결과)**  
① 다시 혼자가 될 텐데 괜찮겠어?  
② 그냥 여기에 계속 있으면 안 돼?  
③ 달로 돌아가지 마.  
→ 흑화 → 족자 밖 도망

**STEP 11–12**  
이무기 등장 → 곰방대 연기로 포획 → 탁기 삼킴 → 옥토끼 복원 / 이무기 한쪽 눈 흰자 검게

**STEP 13**  
① 옥토끼를 구해주세요 → 도플갱어 → STEP 14  
② 계약을 없던 일로 → 재확인 → 히든 엔딩 0 (타이틀 복귀, 세이브 유지, 도전과제)

**STEP 14**  
카드 뒷면(흑토끼) → 앞면(백토끼 둘) → 확대/드래그 앞뒤/재생  
→ 향 3개 선물 → "첫 요괴를 소환해보실까요!" → 소환 화면

## 11. 문서 간 충돌 · 확인 필요 (개발 전 확정)
