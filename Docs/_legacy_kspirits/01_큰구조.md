# 다시...나의 요괴들 — 큰 구조

> 숫자·밸런스·카피 충돌은 보류.  
> 이 문서는 **화면 / 시스템 / 진행축**만 고정한다.

---

## 1. 게임이 하는 일

플레이어는 고가구점에서 **탈출한 요괴를 찾아 족자에 담고**,  
먹이고·놀아주며 **넋 → 괴 → 혼**으로 키운 뒤,  
스토리 선택으로 **승천 또는 악귀화**시키고 **양면 요괴패**로 남긴다.

옥토끼는 예외: 튜토리얼 전용 아크로 끝나고, 이후 **윷놀이·안내 상주**.

---

## 2. 플레이어 여정 (큰 축)

```
[타이틀]
   │
   ▼
[옥토끼 튜토리얼] ─── 조작 학습 + 예외의 법칙 + 세계관 공개
   │
   ├─ 히든0: 계약 해지 → 타이틀 (세이브 유지)
   │
   ▼ 정식: 카드 완성 + 향 3개
[첫 소환] ─── 보장 3인방 중 1마리
   │
   ▼
[본편 육성 루프] ◄──────────────────────┐
   │  공양 / 건드리기 / 윷놀이          │
   │  진화 · 스토리 · 엔딩               │
   ▼                                    │
[요괴패 등록] ─── 엽전 저축 · 향 구매 ───┘
   │
   ▼ (반복)
[도감 수집] · [슬롯 확장] · [재육성…]  ← MVP 이후
```

---

## 3. 화면 구조

허브는 **족자 화면**. 나머지는 족자에서 열고 닫는 위성 화면.

```
타이틀
  └─ 시작 → 족자 (육성 모드) ←── 기본 생활 화면
                │
                ├─ 수련 버튼 → 족자 (수련 모드 / 윷판)
                ├─ 빈 슬롯 → 소환
                ├─ 아이템바 5번 → 인벤토리
                ├─ 엽전 + → 엽전 구매
                ├─ 상점 아이콘 → 상점 (이무기)
                ├─ 도감 아이콘 → 요괴패
                └─ 설정 아이콘 → 설정
```

| 화면 | 역할 |
|------|------|
| 타이틀 | 진입, 완성 요괴 배회 연출 |
| 족자·육성 | 요괴 돌보기, 진화·스토리 발생 지점 |
| 족자·수련 | 윷놀이 (파밍·친밀도) |
| 소환 | 향 3개 → 새 요괴 |
| 인벤토리 | 공양물 선택·지급 |
| 상점 | 엽전으로 소모품·향·슬롯 |
| 도감 | 양면 카드 등록·열람 |
| 엽전 구매 | 현금 → 엽전 |
| 설정 | 사운드·알림·계정 |

**슬롯:** 기본 1 / 최대 3. 옥토끼는 슬롯 안 씀.

## 4. 시스템 맵

서로 맞물리는 덩어리만.

```
┌─────────────────────────────────────────────┐
│                 진행 / 세이브                 │
│   튜토리얼 스텝 · 요괴 인스턴스 · 도감 · 재화   │
└─────────────────────────────────────────────┘
        │              │              │
        ▼              ▼              ▼
   ┌─────────┐   ┌─────────┐   ┌──────────┐
   │  육성    │   │  수련    │   │  소환     │
   │ 기력     │   │ 윷놀이   │   │ 향 3개   │
   │ 친밀도   │   │ 하트     │   │ 랜덤 풀  │
   │ 공양     │   │ 특수칸   │   └──────────┘
   │ 건드리기 │   └─────────┘
   │ 진화     │         │
   │ 스토리   │◄────────┘ (기력·친밀도 보상)
   │ 엔딩     │
   └────┬────┘
        ▼
   ┌─────────┐   ┌─────────┐
   │  도감    │   │  경제    │
   │ 양면패   │   │ 엽전·향  │
   └─────────┘   │ 상점·IAP │
                 └─────────┘
```

### 시스템별 한 줄

| 시스템 | 하는 일 |
|--------|---------|
| **육성** | 기력·친밀도로 상태를 유지하고, 시간+조건으로 진화 |
| **공양** | 아이템 → 기력(+선호면 친밀도). 넋은 정화수만 |
| **건드리기** | 탭 리액션 / 가끔 대사·드롭 |
| **수련** | 하트로 윷 → 이동한 요괴에 기력·친밀도 + 파밍 |
| **진화** | 넋 → 괴 → 혼. 배경·대화·스토리 해금 |
| **스토리** | VN. 혼 3차 선택으로 엔딩 확정 |
| **엔딩** | 승천 / 악귀화 / 도망 |
| **소환** | 향으로 새 요괴를 슬롯에 |
| **도감** | 엔딩 결과를 카드로 저장 |
| **경제** | 윷·상점으로 루프를 돌림 |

## 5. 요괴 생명주기

한 마리가 슬롯에 들어온 뒤의 상태 기계.

```
(소환)
   ▼
[넋] ──시간+기력100+친밀──► [괴] ──시간+기력100+친밀──► [혼]
  │                           │                          │
  │ 정화수만                    │ 소개편                    │ 스토리 1·2·3차
  │ 대화 불가                   │ 대화·공양                  │ 선택지 → 엔딩
  ▼                           ▼                          ▼
도망(기력/친밀도 0 + 유예) ──────────────────────────► 기록 미달
                                                     │
                                    ┌────────────────┴────────────────┐
                                    ▼                                 ▼
                                 승천                              악귀화
                              카드 앞면                           카드 뒷면
                                    └──────── 양면 완성 ──────────────┘
```

옥토끼만 이 생명주기를 타지 않고 **튜토리얼 아크**로 대체.

## 6. 튜토리얼 vs 본편

| | 튜토리얼 (옥토끼) | 본편 (일반 요괴) |
|--|------------------|-----------------|
| 목적 | 조작 + 세계관 + 선택의 무게 | 수집·육성·엔딩 |
| 진화 | 즉시 | 시간 + 조건 |
| 스토리 | 기억 3편 + 흑화 아크 | 소개 + 1·2·3차 |
| 엔딩 | 흑화→복원→소원 (예외) | 승천 / 악귀화 / 도망 |
| 이후 | 슬롯 밖 상주 (윷·안내) | 도감 등록, 슬롯 비움 |

튜토리얼 14스텝은 **족자 화면 안에서** 스텝 머신이 UI·입력을 잠그고 풀어 가며 진행.

```
조작 학습 (1–8) → 기억 (9) → 흑화 (10–12) → 소원 (13) → 카드·향·소환 (14)
```

## 7. MVP에서 실제로 만들 덩어리

우선순위 = 의존 순서.

| 순서 | 덩어리 | 내용 |
|------|--------|------|
| 1 | **셸** | 타이틀 ↔ 족자, 상단 재화/아이콘, 아이템 바 |
| 2 | **요괴 인스턴스** | 단계·기력·친밀도·슬롯 상태 |
| 3 | **튜토리얼 스텝머신** | 14스텝, 입력 제한, 확정 대사 |
| 4 | **공양·건드리기** | 드래그 공양, 탭 리액션 |
| 5 | **윷놀이 (튜토리얼 강제판)** | 빽도→도 시퀀스 → 이후 일반 규칙 |
| 6 | **기억 VN + 선택지** | 흑화·소원 분기 |
| 7 | **카드·도감** | 양면 해금, 향 3개, 소환 진입 |
| 8 | **본편 1마리** | 소환 → 육성 → 엔딩 (튜토리얼과 동일 셸 재사용) |
| 9 | **상점·경제** | 향·정화수·엽전 (루프 닫기) |

1–7이면 “튜토리얼 클리어 → 소환 문 앞”까지.  
8–9면 MVP 완주.

## 8. 지금 고정 / 나중에 채워도 되는 것

**고정**
- 화면 허브 = 족자
- 파라미터 = 기력 + 친밀도
- 수련 = 윷놀이
- 소환 = 향 3개
- 엔딩 = 스토리 선택 (본편) / 튜토리얼 예외 아크
- MVP = 튜토리얼 + 요괴 1마리

**나중에**
- 슬롯·상품 가격, 하트 엽전 비용
- 보장 3인방 최종 이름
- 드롭·완주 보상 테이블
- 23마리 개별 스토리
- 재육성·계열 특혜
