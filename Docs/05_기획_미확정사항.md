## A. PDF 안에서 서로 다른 것

### A1. 자원 기물 레벨업 — "산출시간 −3%/Lv"가 아직 남아 있음
- 1-1 범위 · 8장 레벨업 효과: "자원 기물 산출시간 −3%/Lv + 10Lv마다 보관 +1"
- 7-2 보관 확장 규칙(신규): "생산시간은 Lv1부터 계속 동일, 레벨업은 보관 확장에만", "생산시간 감소 효과 제거"
- **지금 구현:** 7-2 (시간 고정, 보관 확장). → 1-1·8장 문구 정리 필요.

### A2. 요리판 — 본문(19장)과 공양간 기획서가 다름
| | 19장 본문 | 공양간 기획서 | 지금 구현 |
|---|---|---|---|
| 판 | 보유 재료 중 랜덤 **16개** | **5×5**(재료 20 + 빈칸 5) | 5×5 · 빈칸 5 |
| 기본 시간 | **20초** | **15초** | 15초 |
| 회수 부적 | 12초 | 15−4 = 11초 | 11초 |
| 몰빵 부적 | 10초 | 15−5 = 7초(표기 "15→7") | 기획서 기준 |
| 대각선·천리안 | 15초 | 15초(기본과 같음) | 15초 |
| 재료 부족 | 20개 미만이면 확인 팝업, 모자라는 칸은 아래로 | — | 확인 팝업 없음 |
- 어느 쪽이 최신인지 확정 필요. 19장 안에서도 "16개"와 "20개 미만이면"이 섞여 있음.

### A3. 공양물 수치 — 부록 A-3 머리말
- A-3: "기력 +15/+25 · 친밀도 +1, 선호 시 +5" / 본문 5장: 기력 +3 · 친밀도 +2 · 선호 +5
- **지금 구현:** 본문 5장. 부록 머리말 삭제 필요.

### A4. 요리책(도감) 수집 수
- "n/60" 과 "수집 N / 54"가 같이 있음. 레시피는 음식 36 + 공양물 24 = 60(재료까지 넣으면 +13).

### A5. 상점 진열
- 12장 "공양물/향/공양물 순, 3시간마다 랜덤 공양물" vs 같은 줄 "진열 품목이 음식·공양물·재료 중 무엇인지 확인(19장 N)".
- **지금 구현:** 공양물 24종 중 랜덤 2칸 + 향.

## B. 아직 안 정해진 것

### B1. 드래그 "1회차인데 엔딩기물, 떡절구"
6-3 "조건에 맞지 않는 기물(1회차인데 엔딩기물, 떡절구, 이미 점유된 기물)". '1회차'의 뜻 — 1회차엔 떡절구에 **아무도(옥토끼 포함)** 못 앉는지, 주인 아닌 요괴만인지.
- **지금 구현:** 주인(옥토끼)만 앉을 수 있음. 다른 요괴 → (x).

### B2. "엔딩기물 2개"의 정체
8장 "엔딩기물 2개는 전부 떡절구의 레벨에 따른다" — 정의된 엔딩기물은 떡절구 하나. 다른 요괴 엔딩기물이 나올 예정인지, 다른 뜻인지.  
(MVP는 떡절구만 집중)

### B3. 오프라인 중 추가 보관(오버플로우) 판정
방치 수익 `min(보관량, …)`의 "보관량"이 오버플로우 포함인지.
- **지금 구현:** 오프라인도 온라인과 똑같이 판정.

### B4. 윷 말 업기 시 친밀도 +0.25
업힌 채 이동할 때 말마다인지 스택 1회인지.

### B6. 6기물 × 5구역 배치
아트·배치 확정 필요. **지금 구현:** 임시 좌표(`PropLayoutSettings.asset`), 공덕 버드나무 `(0, −1.35)`.

### B7. 걷기 「후보 없음」 vs 「자리 없음」
[`06`](./06_행동룰.md) 기존 모호.

### B8. 부적 완주 보상 종류별 확률
플레이테스트 후 조정. **지금 구현:** 사전 부적 5종 균등(1/5). 나가리는 인벤 아님.

### B9. 황금쌀·황금꿀의 쓰임
7-3에서 인벤토리로 들어간다고만 되어 있음. **지금 구현:** 쌓이기만 함(세이브됨, 표시 화면 없음). 공양간 기획서의 **황금음식**(먹이면 5분 속도 2배)과의 관계 미정.

### B10. 요리판 광고 연장 초수·횟수
14장 "연장 초수·횟수 미정" vs 19-2 "종료 후 광고보고 15초 더, 무제한".

PDF 요약·8장 잔재. **상세 7-2에서 삭제**. `00`은 보관 확장만.
