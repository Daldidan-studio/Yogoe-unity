## 보류 (나중에 정리)

### 1. 요리·사냥·채집 → 인벤 적재

화덕/활터/약초밭 산출 데이터 모델.

- (A) 카테고리별 공양물 랜덤 1개
- (B) `요리`/`사냥`/`채집` 별도 재화 카운터
- (C) 특정 고정 공양물 ID

선물꾸러미·상점·요구와 직결.

### 2. 기물 구매가 수치

지시서 체크리스트 후보: `300 × 1.35^(n−1)`. 본문 수치 깨짐 — 정본 확인 후 `00` 7-2에 반영.

## 미확정 (코드 전 확인)

### 3. 윷놀이 특수 칸 보상 구조

「공양물1·정화수1·엽전1」이 칸 하나당 3종인지, 칸 종류별인지 불명확.

### 4. 말업기(스택)

- 친밀도 +0.25가 스택 전원인지 1회인지
- 이무기가 스택을 잡으면 전체인지

### 5. 걷기 「후보없음」vs「자리없음」

기존 모호 유지 (`06`).

### 일일 리셋 타임존

`00`: 기기 로컬 04:00. 서버/KST 고정이 필요하면 여기로 이슈 올리기.
